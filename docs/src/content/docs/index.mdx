import { Card, CardGrid } from '@astrojs/starlight/components';

**ukanrenix is a pure-Nix μKanren implementation**.
Write relational programs in Nix: unify terms, enumerate answers via lazy streams,
rank solutions by cost, and propagate constraints — all as ordinary Nix expressions.

<CardGrid>
  <Card title="Relational" icon="approve-check">
    Run goals forward or backward. `run n goalFn` enumerates up to n answers as reified Nix values.
  </Card>
  <Card title="Weighted" icon="list-format">
    Tropical semiring search. `weight w goal` scores answers. `wrun` returns top-n by ascending cost.
  </Card>
  <Card title="Constraints" icon="pencil">
    CHR constraint propagation. `typeOf`, `diseq`, and custom predicates deferred until ground.
  </Card>
  <Card title="Gen Integration" icon="nix">
    Backward synthesis over gen-merge, gen-select, gen-scope, and gen-types ecosystems.
  </Card>
</CardGrid>
